# English to IPA Studio 🔤

**An interactive English-to-IPA conversion tool for exploring and comparing American and British English pronunciation.**

English to IPA Studio is a Python application built with Streamlit and eSpeak NG. It converts English words, sentences, and paragraphs into International Phonetic Alphabet (IPA) transcriptions and allows users to compare American and British English pronunciation.

## ✨ Features

- **English-to-IPA Conversion:** Convert English text into phonetic transcriptions.
- **Accent Comparison:** Compare American and British English outputs side by side.
- **Interactive Web Interface:** Explore pronunciations through a modern Streamlit application.
- **Text File Upload:** Import English text from `.txt` files.
- **CSV Export:** Download pronunciation comparisons for further analysis.
- **Input Validation:** Handle empty inputs, unsupported accents, and text length limits.
- **Lightweight Architecture:** Uses eSpeak NG without requiring PyTorch or TensorFlow.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/english-to-ipa-studio.git
cd english-to-ipa-studio
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create and activate a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks script activation, you can run the environment's Python executable directly instead.

### 3. Install Python dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Install eSpeak NG

Download and install eSpeak NG for Windows from the official releases page:

https://github.com/espeak-ng/espeak-ng/releases

The application expects the executable at one of these locations:

```text
C:\Program Files\eSpeak NG\espeak-ng.exe
C:\Program Files (x86)\eSpeak NG\espeak-ng.exe
```

Verify the installation:

```powershell
espeak-ng --version
```

If the executable is installed elsewhere, update `ESPEAK_PATHS` in `phonetics.py`.

## 🚀 Run the Application

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:8501
```

## 🧪 Example

Input:

```text
Hello world
```

The application generates IPA transcriptions for the selected accent or compares both supported accents.

The exact transcription depends on the eSpeak NG voice, its IPA settings, and the pronunciation rules used by the engine.

## 🧠 How It Works

1. The user enters English text or uploads a text file.
2. The Streamlit interface passes the text and selected accent to the conversion module.
3. The Python module invokes eSpeak NG with the appropriate voice.
4. The generated IPA transcription is displayed in the interface.
5. Users can compare outputs and export the results to CSV.

## ⚠️ Limitations

- Transcriptions are generated by a rule-based speech engine and may differ from specialist dictionaries or native-speaker transcriptions.
- Accent selection represents the available eSpeak NG voices, not every regional variety of American or British English.
- The application does not currently assess spoken pronunciation or train its own grapheme-to-phoneme model.
- eSpeak NG must be installed separately from the Python dependencies.
